# Deepthi Krishna A.R — Portfolio

Personal portfolio of Deepthi Krishna A.R, BPT, MPT (Neurosciences), Physiotherapist.

Built with React + Vite, glassmorphism styling, and WebGL hover effects.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Pushing to `main` builds the site and publishes it with GitHub Pages
(repo **Settings → Pages → Source: GitHub Actions**).

Edit content in `src/data.js`.
